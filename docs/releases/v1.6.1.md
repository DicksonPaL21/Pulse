# Pulse Diagnostics v1.6.1 — New name, Windows Server and two-GPU fixes

Pulse is now called **Pulse Diagnostics**, the name it already had in the Microsoft Store. This update also fixes PulseService on Windows Server and the GPU shown on PCs with two GPUs.

## Changes

- **New name: Pulse Diagnostics.** Window and title bar, tray menu, Start menu and desktop shortcuts, Programs and Features, the service in services.msc (*Pulse Diagnostics Service*), report headers and the download files (`PulseDiagnostics-Setup-<version>-windows-x64.exe`). Setup updates an existing install in place: same folder, settings and history, and it removes the old "Pulse" shortcuts.
- **New addresses.** The repository is now [Regncreative/PulseDiagnostics](https://github.com/Regncreative/PulseDiagnostics) and the website [pulsediagnostics.regncreative.com](https://pulsediagnostics.regncreative.com). Old links redirect. Update checks and release links use the new address.
- **PulseService.exe has file version information.** Its Properties → Details tab shows the product name and version, like Pulse.exe.

## Fixes

- **Windows Server** ([#50](https://github.com/Regncreative/PulseDiagnostics/issues/50)). PulseService did not start on Windows Server without the Wireless LAN Service feature: Setup showed "wlanapi.dll was not found" and Pulse stayed offline. Wi-Fi details are now read only when Windows has them.
- **PCs with two GPUs** ([#54](https://github.com/Regncreative/PulseDiagnostics/issues/54)). System Health described the integrated GPU. It now shows the GPU Windows ranks highest for performance, the one apps get when they ask for "high performance". Every GPU stays listed under **GPU → All GPUs**.
- **Idle GPU.** A GPU with nothing running on it showed "—" instead of 0 %, as Task Manager shows it.

## Upgrade notes

- Confirm **Diagnose → Service** shows **1.6.1** after installing.
- An existing install keeps its folder (`C:\Program Files\Pulse`); new installs go to `C:\Program Files\Pulse Diagnostics`. Settings, logs and history stay where they were.
- Releases are not code-signed yet, so SmartScreen may warn about the new file name. See the [Code signing policy](https://github.com/Regncreative/PulseDiagnostics#code-signing-policy).
